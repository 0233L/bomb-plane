# emoji 头像系统

## Goal

给炸飞机加入玩家头像：每位玩家有一个 emoji 头像，首次进入随机分配、可点击自选更换。头像在网页版与小程序版对战相关界面同步显示。原始方案（微信/QQ 登录获取头像）经评估不可行：网页版需企业资质 + 300 元/年认证 + ICP 备案域名（部署在海外 onrender 无法备案），小程序 chooseAvatar 受上架域名限制——本任务不涉及任何登录。

## Requirements

- 每位玩家头像 = 一个 emoji 字符，默认从固定池随机分配，池 ≤ 20 个，内容为"适合做头像"的动物/表情类单码点 emoji（跨平台彩色渲染稳定，避开 ZWJ 连字与肤色修饰符）
- 玩家可点击自己的头像弹出选择面板，从池中自选更换，另有「🎲 随机」按钮
- 头像存储在本地（网页 localStorage 键 `bp_avatar` / 小程序 wx storage 同键），首次访问自动随机分配，坏值自动修复
- 头像随入房带给服务器并随广播回传，显示位置（全部）：
  - 对战页左右面板（自己/对手，含观战视角）
  - 部署页对手名旁
  - 比分牌 tooltip
  - 首页「最近加入的房间」列表
- AI 对手固定 🤖 头像
- 服务器仅纯转发、不校验头像内容（限长防超大 payload）
- 对局中途换头像只改本地显示（对手下一局才看到）——v1 刻意简化，不加新服务器事件
- 网页版与小程序版行为一致

## Acceptance Criteria

- [ ] 20 个以内的单码点 emoji 池，网页与小程序的池完全一致（`diff public/shared.js miniprogram/utils/shared.js` 仍为 IDENTICAL）
- [ ] 首次访问（无 `bp_avatar`）自动随机分配并写入；坏值（不在池内）自动重随机修复
- [ ] 点自己头像弹出选择面板，点选/🎲 随机立即生效并持久化，所有显示我的头像的位置同步刷新
- [ ] 建房/加入房间时带头像上送，`roomCreated`/`joinedRoom`/`opponentJoined`/`battleStart`/`spectatorJoined`/`reconnected`/`rematchStart` 广播均携带双方 `avatars`（与 `names` 同下标）；AI 玩家头像为 🤖
- [ ] 对战面板、部署页对手名、比分牌 tooltip、首页最近房间列表 4 处均显示头像（含观战视角：固定房主在左、玩家在右）
- [ ] 空头像（旧客户端不发）→ 显示空串不崩溃；超长头像被截断（≤8 码元）不报错
- [ ] 断线重连后对手头像仍保留入房时的值
- [ ] 小程序版三页（index/deploy/battle）同样显示头像，首页可换头像
- [ ] 现有 15 个测试全部通过；新增协议层 + jsdom 渲染层测试通过

## Notes

- 协议只加字段，不做向后兼容；客户端 `d.avatars || ['','']` 兜底防旧服务器/旧客户端崩溃
- 房间历史记录（`bp_room_history`）不存头像：列表里都是"我"，统一显示当前头像，老记录零迁移
