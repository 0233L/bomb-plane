# ✈️ 炸飞机（BombPlane）

双人实时对战的网页小游戏：双方各在 10×10 棋盘秘密部署 3 架飞机，按步数规则轮流揭示对方格子，先击中对方 3 个机头者获胜。支持和朋友对战，也支持**人机对战**（电脑会推理，不算好赢），一个人随时能玩。

## 怎么运行

需要先安装 [Node.js](https://nodejs.org)（选 LTS 版即可）。

```bash
npm install   # 第一次运行前安装依赖（只需要做一次）
npm start     # 启动服务器
```

然后浏览器打开 **http://localhost:3000**。

### 自己一个人测试

⚠️ 同一浏览器的所有标签页**共用 localStorage**，两个标签页对战会互相顶掉存档（刷新后身份会串）。
所以：**开一个普通窗口 + 一个无痕窗口**（或 Chrome + Edge 两个浏览器）来模拟两名玩家。

### 和朋友对战

开好房间后点页面顶部的「📋 复制邀请链接」，把链接发给朋友即可——对方打开链接会看到一个**专属的加入界面**（房间号已经藏在网址里，不是菜单、没有创建房间等选项），输入昵称点「加入房间」就进入你的房间。

- 局域网内：朋友连同一个 WiFi，打开你发的 `http://<你的电脑IP>:3000/?room=房间号` 即可
- 互联网上：需要先把项目部署到免费平台（见下文「部署上线」），之后链接自动变成公网网址

## 玩法

1. **部署阶段**：双方各自在棋盘上秘密部署 3 架飞机。
   - 点空白格 = 以该格为机头放置飞机（按当前选中的朝向）
   - 点机身 = 旋转该架飞机（上→右→下→左）
   - 点机头 = 移除该架飞机
   - 点「随机布局」= 一键随机摆 3 架（可反复点击换方案）
   - 飞机可接壤、可贴边，但不能重叠、不能出界
2. **对战阶段**：点对方棋盘上的未知格子进行揭示，结果：
   - 白色 = 空；绿色 = 机身；红色 = 机头（击中机头只标记该格）
   - 对战页左右两侧显示双方昵称、步数和已找到的机头数；上一手揭示的格子用蓝色框标出
   - 同一房间连续对局时，从第二局起棋盘上方居中显示双方累计比分
   - 己方棋盘上每架飞机有不同颜色的轮廓（便于区分），对方打过的位置高亮、没打过的调暗
3. **步数规则**：双方步数相同时**谁先点谁下**（抢步）；步数相差 1 时**只有步数少的一方可以下**。没有先后手之分，落后者可连下两步反超。
4. **胜利**：先击中对方 3 个机头者获胜，这是唯一的结束方式——**任何情况都不判负**。对方断线或离开时对局只是暂停，随时可以回来继续；玩家信息栏的绿点/红点表示双方在线状态。对局结束后**棋盘保留、双方飞机全部公开**：你打过的格子保持结果颜色，没探测过的格子用暗色显示对方飞机的真实位置（观战者同样看得到）——输也输得明白，可以看看对方把飞机藏在了哪。
5. **观战**：房间已有两人时，再进入的人自动坐上观战席——实时看到双方棋盘和揭示过程（看不到任何人的飞机位置）。棋盘上方左侧用 👁+数字 显示观战人数，无人观战时不显示；观战者不能下棋，双方还在部署时显示「对局准备中」等待页，开战后自动进入对局页。
6. **人机对战**：首页点「🤖 人机对战」即可开始（唯一的电脑已是最强档，没有难度选择）。电脑坐在 2 号位，自动部署、自动走棋、对局结束后自动想「再来一局」，和真人流程完全一样（观战、断线重连都兼容）。电脑永不掉线——你断线时对局暂停，回来继续；你离线约 10 分钟房间自动回收。AI 算法见 [ai.js](ai.js)：每步精确枚举所有与已揭示结果不矛盾的三架飞机方案（共 66,816 种里筛剩下的），给每个未知格打分 = **机头概率 + 1.3 × 信息量**（打这格能排除多少方案，按空/机身/机头三种结果的概率加权；权重 1.3 由三轮自对弈模拟共 22,000 余盘实测选定），打分数最高的格子。实测这个组合平均约 19 步找到 3 个机头，明显快于纯追头（约 21.3 步）和纯信息（约 20.1 步）——它天然会"顺藤摸瓜"追着机身找头，同时不放过缩小包围圈的机会。（也试过给它加"一步前瞻"——下棋看两步：四种变体 300 盘自对弈实测全部不如现在的算法，结论和实验代码都记录在 [ai.js](ai.js) 头注释里。）

其他：首页会列出「最近加入的房间」（按最后在线时间从新到旧排序，最多 5 条，已失效的房间会自动从列表删除），点「进入」即可恢复对局；创建/加入房间后网址会带上房间号（`?room=XXXX`），刷新页面、或点「📋 复制邀请链接」转发给朋友，都能直接回到这个房间；首页「📖 游戏规则」按钮弹出简要规则说明（带 4 种朝向的飞机配图）；对局中可点「返回菜单」离开（不判负，之后可从最近房间回来继续）；结束后双方点「再来一局」即可重开。页面右上角的 🌓 按钮可切换主题（浅色 / 深色 / 跟随系统，默认跟随系统，选择会记住）。

## 文件结构（都很短，适合阅读学习）

```
bombPlane/
├── package.json       # 项目说明 + 依赖 + 启动脚本
├── server.js          # 服务器：房间管理、对战逻辑、断线重连（游戏规则全在这里）
├── ai.js              # 人机对战算法（枚举所有可能的飞机布局，计算每个格子的"机头概率"）
├── public/            # 浏览器里运行的部分
│   ├── index.html     # 页面结构（4 个页面：首页/部署/对战/结束）
│   ├── style.css      # 样式
│   ├── shared.js      # 前后端共用的游戏逻辑（飞机形状、摆放校验）
│   └── client.js      # 前端逻辑（渲染棋盘、处理点击）
└── test/
    └── e2e-test.js    # 自动对局测试（模拟两名玩家完整打一局）
```

**防作弊设计**：每架飞机的坐标只存在服务器内存里，浏览器永远收不到对方飞机的位置，
只能看到"哪个格子被揭示成什么颜色"。服务器校验所有操作，客户端改代码也偷看不到。

## 运行自动测试（可选）

```bash
RECYCLE_SECONDS=3 AI_THINK_MIN_MS=80 AI_THINK_MAX_MS=200 node server.js   # 3 秒回收 + 压缩 AI 思考延迟（加速测试）
node test/e2e-test.js                # 另开一个终端运行测试
```

测试会模拟两名玩家走完：建房 → 加入 → 部署 → 步数规则 → 胜利 → 比分累计 → 再来一局 → 断线重连 → 断线不判负 → 离开不判负 → 观战（进入观战席、不能下棋、人数广播、房间回收通知）→ 人机对战（AI 部署/走棋/自动再来一局/断线暂停恢复/观战兼容/房间回收）。

## 部署上线：让全世界的朋友都能玩

分两步：先把代码传到 GitHub，再让 Render 自动部署。都免费，做一次以后就不用管了。

### 第 1 步：把代码传到 GitHub

1. 登录 [GitHub](https://github.com) → 右上角 **+** → **New repository**
2. 仓库名填 `bomb-plane`（被占用就换一个，下面的命令跟着改），选 **Public**，其余默认 → **Create repository**
3. 代码已经在本地建好 git 仓库（提交身份也已配置好），打开终端（在项目文件夹 `bombPlane` 里）执行两条命令即可：

```bash
git remote add origin https://github.com/0233L/bomb-plane.git
git push -u origin main
```

（不喜欢命令行的话，也可以安装 [GitHub Desktop](https://desktop.github.com)：
**File → Add local repository** 选中 bombPlane 文件夹 → **Publish repository**，效果完全一样。）

### 第 2 步：部署到 Render（免费）

1. 注册 [Render](https://render.com)（可以直接用 GitHub 账号登录）
2. 点 **New → Web Service** → 授权连接 GitHub → 选中 `bomb-plane` 仓库
3. 只有两项要填，其余全部默认：
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
4. 方案选 **Free** → 点 **Create Web Service**，等 1~2 分钟变绿（Live）即部署完成
5. 你会得到一个网址，形如 `https://bomb-plane-xxxx.onrender.com`

打开这个网址试试：创建房间 → 点「📋 复制邀请链接」→ 发给朋友 → 朋友打开链接会看到专属的加入界面，输入昵称点「加入房间」即可（邀请链接里的网址会自动用你的 Render 域名）。

### 免费版的两个小限制

- 实例闲置约 15 分钟会休眠，之后第一次打开要等几十秒自动唤醒（网页会自己连上，稍等即可）；
- 房间存在内存里：双方都离线超过 10 分钟房间自动回收，服务器重启对局也会丢失。朋友之间休闲对战完全够用。
