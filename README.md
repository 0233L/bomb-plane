# ✈️ 炸飞机（BombPlane）

双人实时对战的小游戏（**网页版 + 微信小程序版**，两端可以互相联机对战）：双方各在 10×10 棋盘秘密部署 3 架飞机，按步数规则轮流揭示对方格子，先击中对方 3 个机头者获胜。支持和朋友对战，也支持**人机对战**（电脑会推理，不算好赢），一个人随时能玩。

## 🎮 在线游玩

**https://bomb-plane.onrender.com** —— 免费托管，浏览器打开即玩，无需安装任何东西。

- **和朋友对战**：点「创建房间」开好房后，点页面顶部的「📋 复制邀请链接」发给朋友——对方打开链接会看到一个**专属的加入界面**（房间号已经藏在网址里，不是菜单、没有创建房间等选项），输入昵称点「加入房间」就进入你的房间
- **人机对战**：点「🤖 人机对战」直接开打
- **一个人测试**：⚠️ 同一浏览器的所有标签页**共用 localStorage**，两个标签页对战会互相顶掉存档（刷新后身份会串）。所以：开一个普通窗口 + 一个无痕窗口（或 Chrome + Edge 两个浏览器）来模拟两名玩家

> 免费版的两个小限制：实例闲置约 15 分钟会休眠，之后第一次打开要等几十秒自动唤醒（网页会自己连上，稍等即可）；房间存在内存里：双方都离线超过 10 分钟房间自动回收，服务器重启对局也会丢失。朋友之间休闲对战完全够用。

## 玩法

1. **部署阶段**：双方各自在棋盘上秘密部署 3 架飞机。
   - 点空白格 = 以该格为机头放置飞机（按当前选中的朝向）
   - 点机身 = 旋转该架飞机（上→右→下→左）
   - 点机头 = 移除该架飞机
   - 点「随机布局」= 一键随机摆 3 架（可反复点击换方案）
   - 飞机可接壤、可贴边，但不能重叠、不能出界；部署时每架飞机带深色外轮廓，边界一目了然
2. **对战阶段**：点对方棋盘上的未知格子进行揭示，结果：
   - 白色 = 空；绿色 = 机身；红色 = 机头（击中机头只标记该格）
   - 对战页左右两侧显示双方昵称、步数和已找到的机头数；上一手揭示的格子用蓝色框标出
   - 同一房间连续对局时，从第二局起棋盘上方居中显示双方累计比分
   - 己方棋盘：自己的飞机按格子底色显示，对方打过的位置保持原色高亮、没打过的调暗
3. **步数规则**：双方步数相同时**谁先点谁下**（抢步）；步数相差 1 时**只有步数少的一方可以下**。没有先后手之分，落后者可连下两步反超。
4. **胜利**：先击中对方 3 个机头者获胜，这是唯一的结束方式——**任何情况都不判负**。对方断线或离开时对局只是暂停，随时可以回来继续；玩家信息栏的绿点/红点表示双方在线状态。对局结束后**棋盘保留、双方飞机全部公开**：你打过的格子保持结果颜色，没探测过的格子用暗色显示对方飞机的真实位置（观战者同样看得到）——输也输得明白，可以看看对方把飞机藏在了哪。
5. **观战**：房间已有两人时，再进入的人自动坐上观战席——实时看到双方棋盘和揭示过程（看不到任何人的飞机位置）。棋盘上方左侧用 👁+数字 显示观战人数，无人观战时不显示；观战者不能下棋，双方还在部署时显示「对局准备中」等待页，开战后自动进入对局页。
6. **人机对战**：首页点「🤖 人机对战」即可开始（唯一的电脑已是最强档，没有难度选择）。电脑坐在 2 号位，自动部署、自动走棋、对局结束后自动想「再来一局」，和真人流程完全一样（观战、断线重连都兼容）。电脑永不掉线——你断线时对局暂停，回来继续；你离线约 10 分钟房间自动回收。

其他：首页会列出「最近加入的房间」（按最后在线时间从新到旧排序，最多 5 条，已失效的房间会自动从列表删除），点「进入」即可恢复对局；创建/加入房间后网址会带上房间号（`?room=XXXX`），刷新页面、或点「📋 复制邀请链接」转发给朋友，都能直接回到这个房间；首页「📖 游戏规则」按钮弹出简要规则说明（带 4 种朝向的飞机配图）；对局中可点「返回菜单」离开（不判负，之后可从最近房间回来继续）；结束后双方点「再来一局」即可重开。页面右上角的 🌓 按钮可切换主题（浅色 / 深色 / 跟随系统，默认跟随系统，选择会记住）。

## 📱 微信小程序版

网页版和小程序版连的是**同一个服务器**，可以跨端联机：小程序里创建房间，把房间号发给网页端的朋友输入即可加入（反过来也一样）。功能与网页版完全一致：人机对战、观战、最近加入的房间、主题切换、再来一局、断线重连。

### 跑起来（本地开发，可选）

1. 先按「自己运行 / 开发」把服务器跑起来（`npm start`）
2. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，用「导入项目」选中本仓库的 `miniprogram/` 目录
3. AppID 可以先选「测试号」（或注册小程序后填自己的）；开发阶段勾选「不校验合法域名」——小程序端默认连 `ws://localhost:3000/ws`（见 [app.js](miniprogram/app.js) 顶部注释）
4. 点编译即可在模拟器里玩；真机预览时把服务器地址改成电脑的局域网 IP（如 `ws://192.168.1.100:3000/ws`），手机和电脑连同一个 WiFi

### 体验版流程（免费，最多 200 人）

1. 在[微信公众平台](https://mp.weixin.qq.com)注册小程序（**个人主体免费**，无需任何资质）
2. 把注册得到的 AppID 填进 `miniprogram/project.config.json` 的 `appid` 字段
3. 服务器换到有 **wss 合法域名**的地方（小程序真机强制要求 wss + 已备案且主体一致的域名，见下节；开发阶段不校验域名所以没这个限制），并把 `app.js` 顶部的 `SERVER_URL` 改成 wss 地址
4. 开发者工具里点「上传」，到公众平台把该版本**设为体验版**，把体验二维码发给朋友即可试玩

### 正式上架的门槛（本次没做，只记录）

小程序**正式发布**比体验版严格得多，联机游戏大概率需要：注册「游戏」类目；软件著作权或电子版权认证；自审自查报告、隐私政策；**ICP 备案**（域名必须备案且主体与小程序一致——海外服务器无法备案，需要大陆云主机或微信云托管）；**游戏版号**（个人无法申请，需企业主体，周期 4~6 个月）。**体验版（200 人以内）不受这些限制**，这就是当前小程序交付的边界，正式上架时以平台最新规则为准。

## AI 算法（人机对战的电脑）

每步**精确枚举**所有与已揭示结果不矛盾的部署方案（全部 66,816 种合法布局里筛剩下的），给每个未知格打分 = **机头概率 + 0.7 × 机头组信息增益**（打这格能排除多少「机头位置组合」——胜负只看机头在哪，排除机身摆法不同但机头同组的方案对获胜无帮助），打分数最高的格子。

实测平均约 **18.6 步**找到 3 个机头，与信息论估计的理论最优（18~19 步）只差 0.1~0.4 步。公式和权重经过 7 轮、20 余万盘自对弈模拟实测选定（自适应权重、一步前瞻、Rollout 蒙特卡洛、香农熵、Knuth minimax 等 20 余种变体都试过且未通过验收），完整调校史见 [ai.js](ai.js) 头注释。

## 文件结构（都很短，适合阅读学习）

```
bombPlane/
├── package.json       # 项目说明 + 依赖 + 启动脚本
├── server.js          # 服务器：房间管理、对战逻辑、断线重连（游戏规则全在这里）
├── stats.json         # 访客统计（运行时自动生成，Git 已忽略）
├── ai.js              # 人机对战算法（枚举所有可能的飞机布局，按"机头概率 + 机头组信息增益"打分选格）
├── public/            # 浏览器里运行的部分
│   ├── index.html     # 页面结构（4 个页面：首页/部署/对战/结束）
│   ├── style.css      # 样式
│   ├── shared.js      # 前后端共用的游戏逻辑（飞机形状、摆放校验）
│   ├── ws.js          # 原生 WebSocket 客户端（socket.io 兼容接口 + 自动重连）
│   └── client.js      # 前端逻辑（渲染棋盘、处理点击）
├── miniprogram/       # 微信小程序版（同一套协议，可和网页版跨端联机）
│   ├── app.js         # 全局状态 + 事件绑定 + 页面导航（逻辑与 client.js 一致）
│   ├── utils/         # ws.js（wx.connectSocket 版客户端）+ shared.js（与 public 共用）
│   └── pages/         # 首页 / 部署页 / 对战页（含观战等待和结束横幅）
└── test/
    ├── e2e-test.js    # 自动对局测试（模拟两名玩家完整打一局）
    └── mini-logic-test.js  # 小程序端逻辑冒烟测试（mock wx 环境，跨端打完整局）
```

**防作弊设计**：每架飞机的坐标只存在服务器内存里，浏览器永远收不到对方飞机的位置，
只能看到"哪个格子被揭示成什么颜色"。服务器校验所有操作，客户端改代码也偷看不到。

## 📊 访客统计

- 网页首页底部显示「👥 已有 X 位玩家访问过」：每个浏览器/小程序各存一个**匿名 ID**（`localStorage` / 小程序存储 `bp_visitor_id`），同一浏览器一直算同一位访客；清掉浏览器存储（或换设备）算新访客。同一人在网页 + 小程序各算 1 位（两个存储互相独立，这是匿名统计的正常表现）
- **私密明细页**：`/stats?key=XXX`，可看每位访客的平台（网页/小程序）、首次访问、最后访问、访问次数。钥匙来自环境变量 `STATS_KEY`，未设置时默认 `bombplane-stats-2026`；错误/缺失钥匙返回 403。数据不含任何个人信息，默认钥匙只是防止路人顺手打开，上线前可在 Render 后台设置自己的 `STATS_KEY`
- 数据保存在服务器的 `stats.json` 文件里（1 秒防抖落盘、重启自动加载）。同一访客 5 分钟内的重复连接只刷新时间、不重复计次
- **本地备份脚本**（防线上清零）：`node backup-stats.js` —— 每次运行把线上统计快照**追加**到本地的 `stats-backup.jsonl`（不覆盖历史），并打印本地累计去重访客数；服务器休眠清零也不怕，本地有账本。想每天自动备份，用 Windows「任务计划程序」每天运行一次这条命令即可（脚本头注释里有详细说明）。改过 `STATS_KEY` 的话先 `set STATS_KEY=你的钥匙` 再运行
- ⚠️ Render 免费版磁盘是临时的：服务器休眠、重启或重新部署后统计会**从零开始**（本地开发不会）

## 部署上线：让全世界的朋友都能玩

分两步：先把代码传到 GitHub，再让 Render 自动部署。都免费，做一次以后就不用管了。

### 第 1 步：把代码传到 GitHub

1. 登录 [GitHub](https://github.com) → 右上角 **+** → **New repository**
2. 仓库名填 `bomb-plane`（被占用就换一个，下面的命令跟着改），选 **Public**，其余默认 → **Create repository**
3. 代码已经在本地建好 git 仓库（提交身份也已配置好），打开终端（在项目文件夹 `bombPlane` 里）执行两条命令即可：

```bash
git remote add origin https://github.com/0233L/bomb-plane.git
git push -u origin main
```

（不喜欢命令行的话，也可以安装 [GitHub Desktop](https://desktop.github.com)：
**File → Add local repository** 选中 bombPlane 文件夹 → **Publish repository**，效果完全一样。）

### 第 2 步：部署到 Render（免费）

1. 注册 [Render](https://render.com)（可以直接用 GitHub 账号登录）
2. 点 **New → Web Service** → 授权连接 GitHub → 选中 `bomb-plane` 仓库
3. 只有两项要填，其余全部默认：
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
4. 方案选 **Free** → 点 **Create Web Service**，等 1~2 分钟变绿（Live）即部署完成
5. 你会得到一个网址，形如 `https://bomb-plane-xxxx.onrender.com`

打开这个网址试试：创建房间 → 点「📋 复制邀请链接」→ 发给朋友 → 朋友打开链接会看到专属的加入界面，输入昵称点「加入房间」即可（邀请链接里的网址会自动用你的 Render 域名）。
